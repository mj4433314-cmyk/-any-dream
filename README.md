# HR Chat

واجهة محادثة عربية بسيطة ومتجاوبة للموبايل.

## التشغيل
ارفع `index.html` إلى GitHub Pages أو Cloudflare Pages.

**مهم:** هذه النسخة تجريبية؛ الرسائل محفوظة محلياً في جهاز كل مستخدم وليست محادثة مشتركة بين الأعضاء.

لتحويلها إلى محادثة حقيقية بين جميع الأعضاء نحتاج Backend/Realtime مثل Cloudflare Workers + Durable Objects أو خدمة Realtime.
