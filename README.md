# ACCE - منصة العمل والتوظيف

منصة ويب تفاعلية لإدارة فرص العمل والتوظيف والتواصل.

## ✨ المميزات

- 🏠 صفحة رئيسية حديثة
- 👤 ملف شخصي
- 🎬 الاشتراكات والمتابعة
- 📱 محتوى Shorts
- ➕ إضافة محتوى جديد
- 📱 تصميم مستجيب

## 🚀 البدء السريع

1. استنسخ المستودع
2. افتح `index.html` في المتصفح
3. استكشف المنصة

## 📱 الصفحات المتاحة

- `index.html` - الصفحة الرئيسية
- `register.html` - صفحة التسجيل
- `profile.html` - الملف الشخصي
- `videos.html` - الاشتراكات
- `shorts.html` - محتوى Shorts

## 🎨 التصميم

تصميم حديث مع تدرج ألوان جميل وواجهة سهلة الاستخدام.
