# ACCE App - منصة العمل والتواصل

![ACCE Logo](https://img.shields.io/badge/ACCE-App-blue)

## 📱 نظرة عامة

**ACCE** هي منصة حديثة للعمل والتواصل، تجمع بين سهولة الاستخدام والميزات المتقدمة.

## ✨ الميزات الرئيسية

- 🎬 **مقاطع فيديو تعليمية** - تعليمات شاملة للبدء
- 💼 **إدارة التوظيف** - منصة لفرص العمل
- 📊 **لوحة التحكم** - عرض الإحصائيات والمنشورات
- 👥 **إدارة الموظفين** - عرض فريق العمل
- 🎧 **مركز الدعم** - حل المشاكل والاستفسارات
- 🔐 **تسجيل آمن** - نظام تسجيل قوي ومشفر

## 🚀 البدء السريع

### المتطلبات
- متصفح حديث يدعم HTML5
- اتصال بالإنترنت

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/mj4433314-cmyk/ACCE-App.git

# الذهاب للمجلد
cd ACCE-App

# فتح التطبيق
# افتح ملف index.html في المتصفح
```

## 📁 هيكل المشروع

```
ACCE-App/

├── jobs.html           # صفحة التوظيف

├── profile.html        # الملف الشخصي
├── summary.html        # الملخص والإحصائيات

```

## 🎨 التصميم

- **الألوان الرئيسية**: أزرق وبنفسجي
- **الخط**: Segoe UI
- **الاستجابة**: متوافق مع جميع الأجهزة (موبايل، تابلت، ديسك توب)

## 🔧 التقنيات المستخدمة

- **HTML5** - البنية الأساسية
- **CSS3** - التصميم والرسوميات
- **JavaScript (Vanilla)** - التفاعل والوظائف
- **Git** - إدارة الإصدارات

## 📝 الصفحات المتاحة

### 1. الصفحة الرئيسية (index.html)
- عرض الفيديو الترحيبي
- الميزات الرئيسية
- قائمة الموظفين
- التنقل السفلي

### 2. التسجيل (register.html)
- إدخال رقم الهاتف
- كلمة المرور الآمنة
- رمز الكابتشا
- رمز الدعوة
- الموافقة على الشروط

### 3. التوظيف (jobs.html)
- عرض فرص العمل
- المرشحات والبحث

### 4. المنشورات (posts.html)
- أحدث المنشورات
- التفاعل والمشاركة

### 5. الملف الشخصي (profile.html)
- بيانات المستخدم
- الإحصائيات الشخصية
- الإعدادات

### 6. الملخص (summary.html)
- نشاط المستخدم
- الإحصائيات العامة

## 🎯 الوظائف الرئيسية

### التحقق من صحة النموذج
```javascript
- التحقق من ملء جميع الحقول
- التحقق من تطابق كلمات المرور
- التحقق من طول كلمة المرور
- التحقق من الموافقة على الشروط
```

### مفاتيح الاختصار
- رؤية/إخفاء كلمة المرور
- تحديث رمز الكابتشا
- المشاركة السريعة
